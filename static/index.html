Chaos Controls

1. 중복 요청 병렬 방어 (Nonce Replay)

같은 요청이 두 노드에 동시에 도달할 때, 정확히 하나만 승인되는지(Race Condition 방어) 확인합니다.

2. 대규모 트래픽 방어 (L7 DDoS)

짧은 시간에 대량의 요청을 보내 시스템이 초과 요청을 즉각 차단하여 보호하는지 확인합니다.

3. 네트워크 단절 및 복구 (Partition Test)

Node-B의 통신을 끊어 분립시키고, 복구될 때 밀린 데이터(이벤트)를 즉시 동기화(Catch-up)하는지 봅니다.

4. 백엔드 장애 대응 (DB Outage)

백엔드 DB를 멈춰서 모든 노드가 즉시 대기를 멈추고 보호 모드(서킷 브레이커 오픈)에 들어가는지 봅니다.

5. 공유 캐시 장애 대응 (Redis Outage)

중앙 캐시 서버를 죽여서 각 노드가 로컬 캐시(L1)만으로 무중단 버티기를 하는지 봅니다.
